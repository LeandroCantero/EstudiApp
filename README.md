# CursApp - Study Tracker 🎓🚀

Sistema de seguimiento académico para estudiantes de la UNAHUR. Diseñado para centralizar el progreso de la carrera y gestionar estados de materias, notas y créditos.

## 🏹 Objetivo del Proyecto
CursApp permite a los estudiantes llevar un control exhaustivo de su trayectoria académica. Todo el detalle de negocio se encuentra en el [**BRD_CursApp.md**](./BRD_CursApp.md).

## 📂 Estructura del Proyecto

- [**frontend/**](./frontend): Aplicación SPA (React + Vite + TypeScript).
- [**backend/**](./backend): Servidor API REST (NestJS + Prisma + PostgreSQL).

## 🚀 Cómo empezar

### 🌐 Frontend
```bash
cd frontend
npm install
npm run dev
```

### ⚙️ Backend
```bash
cd backend
npm install
npm run start:dev
```

### 🗄️ Base de Datos (Docker)
En la raíz del proyecto:
```bash
docker-compose up -d
```
